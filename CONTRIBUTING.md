# Contributing

This repository is the public product and documentation home for FifthDev. The
production implementation is maintained privately.

Documentation corrections and reproducible beta findings are welcome. Before
opening a pull request, start with an issue that explains what is unclear or
incorrect and the evidence you used to verify it.

Please keep contributions focused, avoid speculative product claims, and never
commit credentials, private source, customer data, generated stores, or local
Fabric state.
