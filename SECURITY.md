# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting flow for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include the affected package/version, a minimal reproduction, impact, and
   any suggested remediation.

Do not include real customer credentials or private source data. Use disposable
test identities and redact tokens, OAuth codes, API keys, keychain values, and
environment secrets.

General setup failures and product feedback belong in the public issue tracker.
