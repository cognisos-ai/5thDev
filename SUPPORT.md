# Support

For setup problems, product questions, and documentation errors, open a
[GitHub issue](https://github.com/cognisos-ai/5thDev/issues).

Please include the smallest useful set of facts:

- `@cognisos/fabric-mcp` version;
- operating system and architecture;
- Node.js version;
- command or product action attempted;
- last successful stage;
- expected and actual result;
- sanitized output from `fabric-mcp doctor` when relevant.

Do not post credentials, OAuth codes, API keys, private source code, keychain
contents, or unredacted environment variables. Sensitive security reports
should follow [SECURITY.md](./SECURITY.md), not a public issue.

This public repository is for FifthDev product information and feedback. The
private production source is not mirrored here.
